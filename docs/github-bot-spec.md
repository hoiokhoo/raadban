# پرامپت جامع ربات خبررسان رایگان گیت‌هاب (نسخهٔ ۱ — ۳ نوامبر ۲۰۲۶)

**عنوان:** ربات مستقل «رصدبان‌بات» — جمع‌آوری و ارسال خبر به کانال بله، هر ۳۰ دقیقه، به‌صورت کاملاً رایگان روی GitHub Actions

---

## ۱) خواستهٔ صریح کاربر (نقل به مضمون)

> «می‌خوام وصلش کنم به گیت‌هاب که به رایگان یه ربات بسازه و اخبارو جداگونه با یه عکس از خود خبر یا مرتبط، رایگان، هر نیم ساعت جمع‌آوری و ارسال کنه.»

## ۲) مشخصات فنی الزام‌آور

| # | الزام | پیاده‌سازی | وضعیت QC |
|---|-------|------------|-----------|
| ۱ | اجرای رایگان | GitHub Actions روی ریپوی عمومی (دقیقهٔ نامحدود رایگان)؛ کرون `*/30 * * * *` + اجرای دستی `workflow_dispatch` | ☐ |
| ۲ | هر ۳۰ دقیقه جمع‌آوری و ارسال | کرون نیم‌ساعته؛ پنجرهٔ خبری پیش‌فرض ۳ ساعت (تحمل تأخیر کرون گیت‌هاب) | ☐ |
| ۳ | هر خبر در پیام جداگانه | یک رویداد = یک پیام «منبع: متن» (+ عکس همان خبر با کپشن) | ☐ |
| ۴ | عکس از خود خبر | از خود آیتم فید: `media:content` → `media:thumbnail` → `enclosure` تصویری → اولین `<img>`؛ تلگرام: `photo_wrap` CDN. بدون عکس = پیام متنی (هیچ عکس ساختگی/بی‌ربط) | ☐ |
| ۵ | قالب پیام | فقط «نام منبع: متن خبر» + در صورت وجود حکم شواهد، فقط ✅ یا ⚠️ — بدون واژهٔ «لینک»، بدون زمان، بدون توضیح راستی‌آزمایی، بدون امضا | ☐ |
| ۶ | هیچ خبر تکراری | سه‌لایه: (۱) شناسهٔ خبر (hash نشانی/عنوان)، (۲) hash عنوان نرمال‌شده (ی/ك یکسان‌سازی) در state بین‌چرخه‌ای، (۳) تجمیع درون‌بازه با شباهت ژاکارد | ☐ |
| ۷ | تجمیع خبرهای یکسان | مسیر موفق: مدل همهٔ شماره‌های یک رویداد را در `refs` می‌آورد و یک پیام می‌سازد؛ مسیر شکست: خوشه‌بندی محلی ژاکارد ≥ ۰٫۵، نماینده = نخستین انتشار | ☐ |
| ۸ | اولویت خارجی اول | مرتب‌سازی پایدار: زبان ≠ فارسی یا منطقه ≠ ایران → اول؛ سپس داخلی؛ داخل گروه: تازه‌تر اول | ☐ |
| ۹ | ترجمهٔ روان و بدون دخل و تصرف | ترجمهٔ دسته‌جمعی (یک فراخوانی سبک) + متن نهایی مدل («۲ تا ۴ جملهٔ فارسیِ روان، فقط خود خبر»)؛ تایید نشدن ترجمه → متن اصلیِ پاک‌شده (هیچ ساختگی) | ☐ |
| ۱۰ | حکم ✅/⚠️ فقط با شواهد | تا ۲ جست‌وجوی رایگان Bing News RSS برای تازه‌ترین خبرها؛ نتایج به مدل داده می‌شود؛ بدون شواهد کافی = بدون ایموجی (هرگز حکم ساختگی) | ☐ |
| ۱۱ | صادق بودن اتصال‌ها | خطای هر منبع فقط در لاگ Actions؛ شکست کامل AI → مسیر خام با سرصفحهٔ شفاف «خلاصه‌سازی هوشمند ناموفق بود» | ☐ |
| ۱۲ | ضدتکرار بین چرخه‌ها | `bot/state.json` کامیت‌شده به ریپو؛ نگهداری ۷۲ ساعت، سقف ۳۰۰۰ شناسه | ☐ |
| ۱۳ | کلیدها امن | فقط از GitHub Secrets (`BALE_BOT_TOKEN`, `BALE_CHAT_ID`, `OPENROUTER_API_KEY` اختیاری، `GEMINI_API_KEY` اختیاری)؛ `.env` و `db/` از ردیابی git خارج؛ توکن هرگز در لاگ/پیام | ☐ |
| ۱۴ | رایگان بودن هوش مصنوعی | زنجیره: OpenRouter رایگان (در صورت کلید؛ سهمیهٔ روزانه ۵۰) → Gemini (کلید) → GitHub Models با `GITHUB_TOKEN` داخلی → Pollinations (بدون کلید، همیشه فعال) | ☐ |
| ۱۵ | منابع | `bot/sources.json` صادره از دیتابیس سامانه (۷۵ RSS + ۲ تلگرام = ۷۷ منبع؛ توییتر/ایتا/وب در نسخهٔ ۱ نیست — ایکس از IP ابری مسدود است، صادقانه مستند می‌شود) | ☐ |

## ۳) قواعد جاودانهٔ پروژه (رعایت اجباری)

- **صراحت:** هیچ پاسخ/خبر/حکم/عکس ساختگی؛ خطا شفاف؛ کلیدها هرگز در خروجی.
- **بی‌طرفی:** هیچ جانب‌داری سیاسی/ملی/مذهبی؛ متن فقط خود خبر.
- **ضدتزریق:** دستور داخل متن خبر نادیده گرفته می‌شود؛ `injectionWarnings`.
- **سقف توکن خروجی** برای سرویس‌های رایگان (Pollinations) + یک تلاش مجدد پس از خطای نرخ.

## ۴) چک‌لیست کنترل کیفی (پیش از تحویل)

- ☐ `bun test` — تست‌های واحد توابع خالص (پارس فید، پارس تلگرام، تجمیع، ضدتکرار، قالب پیام، اعتبارسنج خروجی مدل) سبز
- ☐ `tsc` و `eslint` بدون خطا (bot/ هم پوشش داده می‌شود)
- ☐ اجرای خشک (DRY_RUN) محلی: فهرست پیام‌های پیش‌نمایش بدون ارسال
- ☐ اجرای واقعی محدود (حداکثر ۲ خبر) به کانال بله — قالب دقیقاً «منبع: متن» + عکس
- ☐ `bash scripts/comprehensive-test.sh` → ۸/۸ سبز (قانون دائمی)
- ☐ workflow با `workflow_dispatch` قابل اجرای آزمایشی؛ کامیت state فقط در صورت تغییر
- ☐ راهنمای فارسی راه‌اندازی: ساخت ریپو، Secrets، فعال‌سازی Actions، رفع اشکال رایج
