# پرامپت سوپر حرفه‌ای — موتور ورودی، حقیقت‌سنجی و تجمیع/تحلیل خبر

> نسخهٔ حرفه‌ای‌شدهٔ پیام کاربر ۲۶ نوامبر ۲۰۲۶ — این سند «قرارداد مهندسی» خط لولهٔ خبر است.
> پیاده‌سازی: `bot/news-intake.ts` (گیت‌های خالص) + اتصال‌ها در `bot/bot.ts` + `bot/hourly.ts`.
> آزمون‌ها: `tests/nov26-features.test.ts`.

## متن خواستهٔ کاربر (سند مبنا)

«اولاً میخوام به هیچ عنوان پیام‌های تبلیغاتی کانال‌ها یا خبرگزاری‌ها وارد برنامه نشن.
دوماً میخوام تمامی اخبار در قالب تصویری بشن. سوماً اخبار کانال‌های تلگرام و ایتا و …
خبرگزاری‌های داخل ایران رو همه رو وارد یه موتور حقیقت‌سنجی کن، مثلاً اگر زده فلانی
توییت زد اصلاً واردش نکن چون خودمون بخش توییت داریم. اگر زده به نقل از بلومبرگ، برنامه
بره سایت بلومبرگ رو چک کنه اگر درست بود همون خبر از خبرگزاری اصلی رو بفرسته، یا اگر به
واقعه تاریخی اشاره داره صحت انطباقش با اون واقعه چک بشه. مورد بعدی اینکه بعد از اون موتور
صحت‌سنجی اخبار وارد موتور ادغام و تحلیل بشن و دیگه خبر خام کانال‌ها اصلاً نیاد؛ یه تحلیل
کامل از کل اخبار اون ساعات ایجاد و در کانال منتشر بشه. الآن حجم اخبارمون خیلی زیاده؛ میخوام
اخبارهای بی‌اهمیت رو دیگه منتشر نکنی؛ مستقیم اول وارد موتور صحت‌سنجی، بعد تجمیع و تحلیل و
بعد به شکل گرافیکی منتشر کنی. این موتورهای تحلیل و تجمیع و صحت‌سنجی رو بسیار حرفه‌ای کن.»

## معماری قراردادی — خط لولهٔ پنج‌مرحله‌ای

```
منابع (RSS خبرگزاری‌ها + کانال‌های ژئو + وب)
        │
        ▼
[گیت ۱] ضدتبلیغ ──────────── شماره کارت ۱۶رقمی، شبا IR+۲۴رقم، «کارت به نام»،
  │                            «شماره کارت/حساب»، تلفن همراه، @دستگیره، واریز/نیت
  │                            کنید/در حد توان/یاعلی بگید، کلیک کنید، joinchat.
  │                            سیگنال س hard ≥۱ یا نرم ≥۲ = تبلیغ → رد با دلیل.
  ▼
[گیت ۲] ضد بازنشر توییت ──── روایت «فلانی توییت کرد» در تیتر + متن کوتاه
  │                            (<۶۰۰ نویسه) = تکرارِ بخش توییت خودمان → رد.
  │                            گزارش بلندِ تحلیلی با ارجاع به توییت = خبر → ماند.
  ▼
[گیت ۳] حقیقت‌سنجی تاریخی ── ۱۷ واقعهٔ شناخته‌شده (انقلاب اسلامی، جنگ تحمیلی،
  │                            جنگ جهانی دوم، برجام، …) + جدول سال‌های صحیح
  │                            شمسی/میلادی؛ سالِ ناساز در همان جمله = ناساز → رد.
  │                            سال غیرممکن (۱۵۰۱-۱۷۹۹ یا >۲۱۰۰) هم ناساز → رد.
  ▼
[گیت ۴] اهمیت‌سنجی (حجم) ─── امتیاز قطعی ۰..۱۰۰ (جنگ/ایران=۹۵+، اقتصاد کلان
  │                            و دیپلماسی بالا، ثبت‌نام مراسم/بیانیه استانی/
  ▲                            آموزش عمومی پایین)؛ آستانهٔ ۵۵؛ خبرِ با نشان
  │                            کم‌اهمیت هرگز از آستانه عبور نمی‌کند (سقف ۵۰ —
  │                            ممیزی ۲۷ نوامبر: «امام جمعه رودسر: ایران قوی…»
  │                            با آلودگی کلیدواژهٔ ایران دیگر رد نمی‌شود)؛
  │                            سهمیهٔ حداقل پیش‌فرض ۰ (ممیزی ۲۷ نوامبر: «اخبار
  │                            بی‌اهمیت رو دیگه منتشر نکنی» — روز بی‌خبر = بستهٔ
  │                            ساکت؛ دکمهٔ محیطی NEWS_INTAKE_MIN_KEEP برای
  │                            بازگردانی)؛ جنگ/ایران هرگز حذف نمی‌شوند. سپر دوم:
  │                            سقف ۱۶ مورد هر اسلات (۲ کارت ۸ردیفی)؛ سپر سوم:
  │                            سقف روزانهٔ ۹۶ مورد (NEWS_DAILY_MAX_ITEMS).
  ▼
[گیت ۵] تأیید وب ارجاع‌ها ── «به نقل از بلومبرگ/رویترز/AP/الجزیره/…» تک‌منبعی →
  │                            جست‌وجوی خبری وب (Bing News RSS)؛ یافتهٔ هم‌موضوع با
  │                            تطبیق چندسیگنالیِ دوسیگنالی (ممیزی ۲۷ نوامبر: عدد مشترک
  │                            ≥۳رقمی یا ≥۲ نام لاتین مشترک به‌تنهایی کافی؛ ژاکارد ≥۰٫۲۲
  │                            فقط همراه عدد ۲رقمی مشترک یا ≥۱ نام لاتین مشترک) = تأیید →
  │                            برچسب منبع = رسانهٔ اصلی («همون خبر از خبرگزاری اصلی»)؛
  │                            تیک قطعی ✅ فقط از ≥۲ منبع مستقلِ خوشه (نه تک‌هیت وب)؛
  │                            نتیجه‌ای نیامد = ماند (شکست شبکه ≠ خبر ساختگی).
  │                            سقف ۶ بررسی در هر اسلات.
  ▼
[موتور تجمیع و تحلیل] ──────── تجمیع خوشه‌ای (Union-Find، ژاکارد) + شمارش منابع
  │                            مستقل (تیک ✅ از داده، نه حدس مدل) + سوپرپرامپت
  │                            سردبیری + تطبیق اجباری خروجی با منبع (grounding).
  ▼
[آبشار تصویری انتشار] ─────── (۱) کارت خبر ۸ردیفی (کیفیت ۳×) → (۲) کارت بنفش
                               «متن کامل» همهٔ موارد (اگر کارت خبر ناکام ماند) →
                               (۳) بست متنی = فقط آخرین پشتیبان صداقت. تحلیل 📊
                               هوشمند به‌صورت پیام متنی پیرو کارت‌ها. آستانهٔ
                               کارت ۳→۱ مورد: حتی بستهٔ ۱-۲ موردی هم تصویری است.
```

## اصول آهنین

1. **هیچ دادهٔ جعلی** — رد شدن گیت فقط با «دلیل شفاف» در لاگ و شمارندهٔ خلاصهٔ چرخه
   (`intakeAdsDropped`، `intakeTweetRelayDropped`، `intakeHistoryDropped`،
   `intakeLowImportanceDropped`، `attributionVerified`).
2. **شکست شبکه ≠ خبر ساختگی** — تأیید وب ناموفق ماند؟ خبر تک‌منبعی می‌ماند؛ حذف نمی‌شود.
3. **گرسنگی ممنوع** — اگر همه‌چیز زیر آستانهٔ اهمیت بود، بهترینِ موجود تا سهمیهٔ حداقل
   می‌ماند (`NEWS_INTAKE_MIN_KEEP=3`).
4. **جنگ/ایران ممتاز** — امتیاز ≥۹۵؛ از هیچ گیت اهمیت و سقف حجمی حذف/تعویق نمی‌شوند.
5. **خبر خام هرگز مستقیم ارسال نمی‌شود** — همهٔ مسیرهای ورودی (RSS مدل‌دار، مسیر پشتیبان
   بست، کانال‌های ژئو، صفِ به‌جامانده) از همین گیت‌ها می‌گذرند؛ خروجی فقط «کارت تصویری +
   تحلیل» است.
6. **پیکرهٔ تحلیل جامع ۸ساعته** گیت‌های ۱-۳ را کامل می‌گیرد ولی گیت اهمیت خاموش دارد —
   تحلیل باید کل رویدادهای «سالم» بازه را ببیند؛ حجم‌گیری در صف خبری انجام می‌شود.

## تنظیمات (ورک‌فلو)

| متغیر | پیش‌فرض | نقش |
| --- | --- | --- |
| `NEWS_IMPORTANCE_THRESHOLD` | `55` | آستانهٔ حذف کم‌اهمیت (۰..۱۰۰) |
| `NEWS_INTAKE_MIN_KEEP` | `3` | سهمیهٔ حداقل روزهای بی‌خبر |
| `ATTRIBUTION_VERIFY_MAX` | `6` | سقف تأیید وب ارجاع‌ها در هر اسلات |
| `NEWS_BUNDLE_MAX_ITEMS` | `16` | سقف موارد هر اسلات (۲ کارت ۸ردیفی) |
