## جلسه ششم (۳۰ اکتبر ۲۰۲۶) — نسخه ۱٫۱: خوانش کانال‌ها + راستی‌آزمایی پیام‌به‌پیام + ترجمه + سه‌تقویم + رویدادهای پیش رو

### قابلیت‌های تازه
- **خوانش کانال‌ها (تب جدید):** سنجاق کانال عمومی تلگرام/ایتا/بله + نمایش پیام‌رسان‌مانند (حباب RTL، سه‌تقویم هر پیام، نشان فوروارد، بارگذاری قدیمی‌ترها، همگام‌سازی دستی) — دریافت واقعی از اتصال‌دهنده‌های موجود
- **راستی‌آزمایی پیام با AI:** کلیک روی پیام → دکمه «راستی‌آزمایی کامل با هوش مصنوعی» → تفکیک متن به سگمنت‌های رنگی (درست سبز/نادرست قرمز/گمراه‌کننده کهربایی/تأییدناپذیر طوسی/نظر بنفش) + توضیح هر بخش + مبنای حکم + حکم کلی + خلاصه + نتیجه‌گیری + هشدار تزریق؛ ذخیره در MessageFactcheck (بازبینی بدون هزینه)؛ برچسب «ممکن است خطا داشته باشد»
- **ترجمه فارسی روان:** SYSTEM_TRANSLATE نسخه‌دار؛ دکمه ترجمه برای مطالب خارجی در جست‌وجو (Post) و پیام‌ها (ChannelMessage)؛ ذخیره در فیلدهای ترجمه
- **سه‌تقویم:** hijriDisplay (ام‌القری با locale فارسی) + gregorianDisplay + کامپوننت TripleDate — در داشبورد، پیام‌ها، رویدادها، نتایج جست‌وجو
- **رویدادهای پیش رو (تب جدید):** ۸ رویداد واقعی مستند با منبع — میان‌دوره‌ای آمریکا ۳ نوامبر (۴ روز مانده) با نظرسنجی مستند CNN ۵۲/۴۳ + ترکیب کنگره ۲۱۹/۲۱۳ و ۵۳/۴۷ + لینک ردیاب زنده؛ COP31 آنتالیا ۹-۲۰ نوامبر؛ G20 میامی ۱۴-۱۵ دسامبر؛ فرانسه (تقریبی)؛ کنست (صادقانه نامشخص)؛ داووس ۲۰۲۷؛ کنگره حزب کمونیست چین؛ اکسپو بلگراد — تحلیل AI با مقایسه سناریوها (احتمال‌گذاری متنی) با دکمه تولید

### اصلاحات کیفیت در همین جلسه
- `segmentsJson` در MessageFactcheck بدون پیش‌فرض بود → مسیر خطای ثبت را می‌شکست؛ @default("[]") + همه createها به upsert تبدیل شد (خطای unique در بررسی مجدد)
- `aiCall` بدون timeout بود → هنگ SDK اسلات هم‌زمانی را قفل می‌کرد؛ محافظ ۹۰ ثانیه‌ای Promise.race اضافه شد
- رندر سگمنت معیوب کل صفحه را می‌انداخت → فیلتر دفاعی در FactcheckView
- تاریخ بازه‌ای رویداد ('تا' وسط ISO) خطای Invalid time value می‌داد → جدا شدن تاریخ پایان + سخت‌سازی TripleDate در برابر تاریخ نامعتبر
- مرتب‌سازی رویدادها: تاریخ‌دار به ترتیب نزدیکی اول، بدون‌تاریخ آخر
- سگمنت‌سازی: نگاشت نرمال→خام با حذف نیم‌فاصله برای تطبیق quoteهای بدون نیم‌فاصله

- باگ سوم (کشف در تست زنده): فراخوانی‌های پس‌زمینه خط تولید (پشتیبانِ ۳٬۷۵۷ پست خام) صف هم‌زمانی را اشغال می‌کردند و درخواست کاربر برای همیشه منتظر می‌ماند (starvation)

### معماری تازه — الگوی FCC (free-claude-code، github.com/Alishahryar1)
- `src/lib/ai/providers.ts`: زنجیره تأمین‌کنندگان + هسته انتقال خطا (تابع خالص قابل تست)
  - ترتیب پیش‌فرض: zai (داخلی، همیشه اول) → FCC (سرور محلی free-claude-code، `FCC_BASE_URL` با پیش‌فرض `http://127.0.0.1:8787/v1`) → Groq → OpenRouter → NVIDIA NIM → GitHub Models → Together
  - هر تأمین‌کننده فقط با کلید محیطی فعال می‌شود (`GROQ_API_KEY`، `OPENROUTER_API_KEY`، `NVIDIA_API_KEY`، `GITHUB_TOKEN`، `TOGETHER_API_KEY`، `FCC_API_KEY`)؛ بی‌کلید = رد شفاف با توضیح
  - تعریف سفارشی کاربر با Setting «ai_providers» (JSON) — جایگزین کامل زنجیره؛ zai همیشه اول مگر صریحاً غیرفعال شود
  - `openAiCompatibleCall`: POST `{baseUrl}/chat/completions` بدون SDK — timeout با AbortController، تایمر پاک‌سازی می‌شود، تشخیص 429
  - `runChain`: هر مدل حداکثر ۲ تلاش؛ 429 → تأخیر ۴ث و تلاش دوباره همان مدل؛ سایر خطاها → مدل بعدی؛ سقف ۱۸۰ث؛ شکست کامل → خطای تجمیعی با دلیل تک‌تک مدل‌ها
- `src/lib/ai/client.ts` بازنویسی: بودجه، ضدتزریق، صف هم‌زمانی و ثبت AiUsage حفظ شد؛ model ثبت‌شده = «provider/model» واقعی
- **اولویت صف**: `priority: 'interactive'` برای دکمه‌های کاربر (ارزیابی ادعا، راستی‌آزمایی پیام، تحلیل رویداد، کشف منبع) — سر صف می‌ایستد؛ خط تولید پس‌زمینه نرمال
- **قطع‌کن مدار**: ۶ خطای 429 پیاپی → تلاش پس‌زمینه ۵ دقیقه معلق (بدون مصرف منابع)؛ درخواست کاربر همیشه تلاش واقعی می‌کند؛ موفقیت قطع‌کن را می‌بندد
- `callZaiModel` استخراج شد: timeout ۷۵ث با تایمر پاک‌شونده (نشتی تایمر نسخه قبل رفع شد)

### صحت‌سنجی زنده (curl روی سرور واقعی)

6. پنل جدید «ربات بله» در UI + کارت «کلیدها و مانده/مصرف توکن» در بخش مدل و API

### تغییرهای الگوریتمی (`src/lib/pipeline/clustering.ts`)
- **مدل «نمایندهٔ اول» جای Union-Find زنجیره‌ای:** هر پست فقط به کهن‌ترین پستِ خوشه‌ای می‌پیوندد که شباهت ≥ آستانه دارد. چرا؟ در مدل زنجیره‌ای A≈B و B≈C دو خبرِ بی‌ربط A و C را در یک خوشه می‌ریزد و «اولین منبع» را غلط نشان می‌داد — بدترین خطای ممکن برای ردیابی منشأ. (تست ضد-drift اضافه شد.)
- **توکن‌های معنادار:** حذف استوپ‌ورد فارسی/انگلیسی + کلمات <۳ حرفی؛ اعداد دقیق حفظ می‌شوند («۲۵» ≠ «۳»)؛ نیم‌فاصله/ی-ک عربی نرمال.

- **سرعت:** مجموعه توکن‌ها فقط یک‌بار per-post محاسبه می‌شود + هرس نسبت‌اندازه (کران بالای جاکارد) — ساخت کامل ۲۵۰۰ پست: **~۲ ثانیه** (قبلاً توکنایز در هر جفت).
